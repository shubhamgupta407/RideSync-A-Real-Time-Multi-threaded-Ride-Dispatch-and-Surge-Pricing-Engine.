How This C++ Architecture Works
std::thread + mutex + condition_variable
1. Thread-Safe Queue Rider requests wait in a locked C++ queue. A condition_variable wakes the dispatcher instantly without CPU busy-waiting.
2. Euclidean Matching When a ride is requested, the dispatcher locks driver_mutex and calculates shortest straight-line distance √(Δx² + Δy²).
3. Dynamic Surge Zones The grid is divided into zones. If pending requests exceed available drivers by ≥1, fares multiply (1.5x - 2.0x) automatically.
